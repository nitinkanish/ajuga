# Ajuga

Ajuga is an iPhone expense tracker. Balances, expenses, credits, daily activity, outdoor sessions, and phone heat stay on the device.

Version 1.0.0 (build 2). Bundle ID `com.debugged.aster.aster`.

## Install file

The iPhone build is in this repository:

[dist/Ajuga.ipa](dist/Ajuga.ipa)

Direct download:

https://github.com/nitinkanish/ajuga/raw/main/dist/Ajuga.ipa

This is a development install signed for the Debugged Apple team (`YLKU69SJ9T`). It runs only on iPhones already registered on that team. The provisioning profile is valid until 22 September 2027. After the app is installed, the USB cable can be unplugged.

## Install on an iPhone

1. Download `Ajuga.ipa`.
2. Connect the iPhone to a Mac.
3. Open the file in Apple Configurator or Xcode and install it on the phone.
4. On the iPhone, open Settings → General → VPN & Device Management and trust the developer if iOS asks.
5. Open Ajuga. The cable is only needed for this install.

A phone that is not registered on the Debugged team will be rejected until its device ID is added to the team.
